### 2.4 实现 RR_enqueue [S71]

**位置**：RR_init 下方

**任务**：将进程加入运行队列尾部

**思考过程**：
1. 先检查进程是否已在队列中（断言）
2. 将进程的 `run_link` 添加到链表尾部
3. 处理时间片（如果为 0 或无效，重置为最大值）
4. 设置进程所属队列
5. 更新计数

**代码实现**：

```c
static void
RR_enqueue(struct run_queue *rq, struct proc_struct *proc)
{
    // LAB6: YOUR CODE
    
    // Step 1: 断言检查 - 确保进程不在任何队列中
    // 如果 run_link 不是孤立的（非空），说明已入队，这是错误的
    assert(list_empty(&(proc->run_link)));
    
    // Step 2: 将进程插入队列尾部
    // run_list 是链表头，list_add_before 会插入到头节点之前
    // 在循环链表中，头节点之前就是队尾
    list_add_before(&(rq->run_list), &(proc->run_link));
    
    // Step 3: 时间片处理
    // 如果时间片为 0（刚用完）或大于最大值（异常），重置
    if (proc->time_slice == 0 || proc->time_slice > rq->max_time_slice)
    {
        proc->time_slice = rq->max_time_slice;
    }
    
    // Step 4: 记录进程所属的运行队列
    proc->rq = rq;
    
    // Step 5: 增加队列中的进程计数
    rq->proc_num++;
}
```

**为什么用 `list_add_before` 而不是 `list_add_after`？**

```
链表结构（循环双向）：
                      ↙─────────────────────────↖
run_list(head) ←→ P1 ←→ P2 ←→ P3 ←→ run_list(head)
       ↑                              ↑
    队头方向                       队尾方向

list_add_before(&run_list, new):
  在 run_list 之前插入 = 在 P3 之后插入 = 插入队尾 ✓

list_add_after(&run_list, new):
  在 run_list 之后插入 = 在 P1 之前插入 = 插入队头 ✗
```

### 2.5 实现 RR_dequeue [S72]

**位置**：RR_enqueue 下方

**任务**：将进程从运行队列移除

**思考过程**：
1. 先检查进程确实在队列中（断言）
2. 从链表删除
3. 更新计数

**代码实现**：

```c
static void
RR_dequeue(struct run_queue *rq, struct proc_struct *proc)
{
    // LAB6: YOUR CODE
    
    // Step 1: 断言检查
    // 确保 run_link 不为空（在某个链表中）
    // 确保进程属于当前队列
    assert(!list_empty(&(proc->run_link)) && proc->rq == rq);
    
    // Step 2: 从链表中删除，并重新初始化 run_link
    // list_del_init 会删除节点，并让节点变成孤立状态
    list_del_init(&(proc->run_link));
    
    // Step 3: 减少队列中的进程计数
    rq->proc_num--;
}
```

### 2.6 实现 RR_pick_next [S73]

**位置**：RR_dequeue 下方

**任务**：选择队头的进程

**思考过程**：
1. 获取队头元素（head 的 next）
2. 判断队列是否为空
3. 转换链表节点为进程指针

**代码实现**：

```c
static struct proc_struct *
RR_pick_next(struct run_queue *rq)
{
    // LAB6: YOUR CODE
    
    // Step 1: 获取队头元素
    // list_next 返回 run_list 的下一个节点
    list_entry_t *le = list_next(&(rq->run_list));
    
    // Step 2: 判断队列是否为空
    // 如果 next 指向 run_list 自己，说明队列为空
    if (le != &(rq->run_list))
    {
        // Step 3: 转换为进程指针
        // le2proc 通过 run_link 字段的地址反推 proc_struct 地址
        return le2proc(le, run_link);
    }
    
    // 队列为空，返回 NULL
    return NULL;
}
```

### 2.7 实现 RR_proc_tick [S74]

**位置**：RR_pick_next 下方

**任务**：处理时钟中断，更新时间片

**思考过程**：
1. 如果时间片还有剩余，减一
2. 如果时间片耗尽，设置调度标志

**代码实现**：

```c
static void
RR_proc_tick(struct run_queue *rq, struct proc_struct *proc)
{
    // LAB6: YOUR CODE
    
    // Step 1: 减少时间片（如果还有剩余）
    if (proc->time_slice > 0)
    {
        proc->time_slice--;
    }
    
    // Step 2: 检查时间片是否耗尽
    if (proc->time_slice == 0)
    {
        // 设置需要调度标志
        // trap 返回时会检查此标志，并调用 schedule()
        proc->need_resched = 1;
    }
}
```

### 3.6 步骤 5：实现 stride_pick_next [S79]

**这是最关键的函数！**

**思考过程**：
1. 找到 stride 最小的进程
2. 更新该进程的 stride
3. 返回进程指针

**代码实现**：

```c
static struct proc_struct *
stride_pick_next(struct run_queue *rq)
{
    /* LAB6 CHALLENGE 1: YOUR CODE */
    
#if USE_SKEW_HEAP
    // (1.1) 斜堆实现：堆顶就是最小元素
    if (rq->lab6_run_pool == NULL)
    {
        return NULL;  // 队列为空
    }
    
    // 获取堆顶进程
    struct proc_struct *p = le2proc(rq->lab6_run_pool, lab6_run_pool);
    
#else
    // (1.2) 链表实现：需要遍历找最小值
    if (list_empty(&(rq->run_list)))
    {
        return NULL;
    }
    
    list_entry_t *le = list_next(&(rq->run_list));
    struct proc_struct *p = le2proc(le, run_link);
    
    // 遍历链表找最小 stride
    while ((le = list_next(le)) != &(rq->run_list))
    {
        struct proc_struct *proc = le2proc(le, run_link);
        // 使用有符号差值比较（处理溢出）
        if ((int32_t)(proc->lab6_stride - p->lab6_stride) < 0)
        {
            p = proc;
        }
    }
#endif

    // (2) 更新 stride 值
    // stride += BIG_STRIDE / priority
    if (p->lab6_priority == 0)
    {
        // 避免除零错误
        p->lab6_stride += BIG_STRIDE;
    }
    else
    {
        p->lab6_stride += BIG_STRIDE / p->lab6_priority;
    }
    
    // (3) 返回选中的进程
    return p;
}
```
