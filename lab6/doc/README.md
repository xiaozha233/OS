## 🔖 快速参考

### 关键常量

```c
#define MAX_TIME_SLICE 5        // 最大时间片
#define BIG_STRIDE 0x7FFFFFFF   // 大步幅常数 (2^31 - 1)
```

### 五个核心函数

| 函数 | RR 实现 | Stride 实现 |
|:---|:---|:---|
| init | 初始化链表 | 初始化链表 + 斜堆 |
| enqueue | 插入队尾 | 插入斜堆 |
| dequeue | 删除节点 | 从斜堆删除 |
| pick_next | 取队头 | 取堆顶 + 更新 stride |
| proc_tick | 减时间片 | 减时间片 |

### 公式速记

- pass = BIG_STRIDE / priority
- stride_new = stride_old + pass
- 调度次数比 ≈ 优先级比
