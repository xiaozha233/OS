> **讲义版本**: 1.0  
> **覆盖标签**: [S01] - [S12]  
> **难度等级**: ⭐⭐⭐⭐（中高级）

## 🎯 学习目标

欢迎来到 Lab6 进程调度实验！本实验是操作系统课程中非常核心的一环。完成本实验后，你将能够：

1. **理解**操作系统调度管理机制的基本原理 [S01]
2. **熟悉** ucore 的调度器框架设计思想 [S02]
3. **实现** Round-Robin（RR）时间片轮转调度算法 [S03]
4. **实现** Stride Scheduling 调度算法 [S04]
5. **掌握**如何在 C 语言中模拟面向对象的编程模式

## 📁 项目结构导览

本实验的主要文件分布如下，标注★的是你需要重点关注和修改的文件：

```
lab6/
├── kern/
│   ├── schedule/               ← 【核心目录】调度相关代码
│   │   ├── sched.h             ← 调度器框架头文件（定义数据结构）
│   │   ├── sched.c             ← 调度器框架实现
│   │   ├── default_sched.h     ← 默认调度器头文件
│   │   ├── default_sched.c ★   ← 【练习2】RR调度算法实现
│   │   └── default_sched_stride.c ★ ← 【Challenge】Stride算法实现
│   ├── process/
│   │   ├── proc.h              ← 进程控制块定义（含调度相关字段）
│   │   └── proc.c ★            ← 进程管理（需更新初始化代码）
│   ├── trap/
│   │   └── trap.c ★            ← 中断处理（时钟中断调用调度器）
│   └── init/
│       └── init.c              ← 内核初始化（调用sched_init）
├── libs/
│   ├── skew_heap.h             ← 斜堆数据结构（Stride算法使用）
│   └── list.h                  ← 双向链表实现（RR算法使用）
└── user/
    ├── priority.c              ← Stride算法测试程序
    ├── matrix.c                ← 矩阵运算测试
    └── ...                     ← 其他测试程序
```

1. **C 语言基础**：指针、结构体、函数指针
